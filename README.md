# Neural-Network Activation Memory Optimization

A Discovery@Home research pilot for minimizing peak activation memory at a
fixed recomputation budget. It contains an independent schedule verifier, exact
small-graph solver, seeded optimizer, fixed benchmark suite and explicit certificates.
**No GPU memory or speed improvement is claimed.**

The [30-minute trial](research/trial-30m/REPORT.md) improved 17 existing graph/budget
records across five graphs, with a first verified improvement after 2m04s. The trial
remains author-checked and awaits independent review. Its [candidate records](research/trial-30m/candidates.json)
and [21 unresolved cases](research/trial-30m/remaining-tasks.json) must be consulted
before new search; the authoritative table below preserves the pre-trial snapshot.

```sh
python3 verify_all.py
```

Python 3.9+ and its standard library are sufficient. The full check is intended to
finish in under two minutes and normally takes seconds. Expected output ends with
`PASS: complete offline pilot verification`. No neural-network training is needed.

Initial authoritative frontier: 12 graphs, 60 graph/budget cases, 25 exact tiny optima,
418 verified baseline certificates. The final sweep improves
24/60 cases over tuned baselines, including
17/35 workload-derived cases. These are baseline-relative
model records, not global research records. See [the report](research/initial/REPORT.md),
[frontier table](records/frontiers.json), and [model](MODEL.md).

The underlying problem has established exact and heuristic approaches, including
[Checkmate](https://arxiv.org/abs/1910.02653v3) and
[Moccasin](https://proceedings.mlr.press/v202/bartan23a.html).
[LITERATURE.md](LITERATURE.md) states what is reproduced and what remains untested.

```sh
# Check one explicit certificate against its fixed challenge budget.
python3 verifier.py benchmarks/graphs/chain6-unit.json certificates/frontier/chain6-unit-b6.json --budget 6
# Recompute every exact small optimum and verify all table records.
python3 run_suite.py check --exact
# Discover a schedule for a selected instance (write to a new path).
python3 search.py benchmarks/graphs/transformer-b2-t64.json --budget 55410688 --seed 42 --iterations 600 --out candidate.json
# Deterministically regenerate the campaign in a scratch checkout.
python3 run_suite.py build
# Pick an open task with a recorded OS-generated seed.
python3 project_tools.py pick
```

The fixed suite is generated by `generate.py`; `--check` detects any drift.
Records are in `records/`, certificates in `certificates/`, research evidence in
`research/initial/`, and PyTorch CPU evidence separately in `empirical/`.
The optional PyTorch probe and exact dependency pins are described in
[empirical/COMPARISON.md](empirical/COMPARISON.md). It is not needed to verify schedules.
